Proofread `${ARGUMENTS:-the file I am currently working in}`.

**1. Read it all first.** `read` for text and Markdown; `document_read` for Word or PDF. Pasted text may have lost its line breaks — keep the paragraphing I would obviously intend.

**2. Fix what is wrong, keep what is theirs.**

- Fix spelling, grammar, punctuation, typos, repeated words, broken sentences, inconsistent terms and capitalization.
- Tighten sentences that are genuinely unclear. Do not rewrite sentences that are merely not how you would say them.
- Keep the author's voice, register and language (British or American spelling as the text already uses it). Do not add content, remove arguments or change meaning.
- Leave code, URLs, names, quotations and numbers alone unless one is plainly a typo — then flag it rather than fix it.

**3. Show the result:** the corrected text, then a list of every change as `before → after`, grouped as *errors* and *clarity*. Keep the clarity list short; if there are only errors, say so.

**4. For a file:** show the list and ask before writing. When I agree, edit the file in place — for a Word or PDF file, write a corrected `.md` beside it instead, since those cannot be edited here.
