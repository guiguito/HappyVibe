# Memory (PRD §33) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The agent remembers durable facts across sessions through three gated, audited, visible tools; the user sees every memory, edits it, forgets it, imports Claude Code's, and sees its per-turn cost.

**Architecture:** Main owns the store (`src/main/memory/`, electron-free, dirs as params — the `src/main/skills/` shape) and is the ONE writer: agent saves arrive as blocking `hv.memory-*` envelopes (the `hv.plan-write` pattern), human edits arrive over IPC, both go through one serialized queue that writes atomically and regenerates the `MEMORY.md` index. The bridge registers `memory_save` / `memory_recall` / `memory_forget` under `builtins.memory`, re-reads both indexes from disk in `before_agent_start` every turn (zero respawns), and reports their weight in the `/hv-context` snapshot. Renderer adds a Memory page, a workspace section, cards, a context-panel category, a Built-in tools row and audit labels.

**Tech Stack:** TypeScript 7 (`npm run typecheck` is inside `npm run build`), vitest, `yaml` (root dep, already pinned to Pi's), TypeBox (`pi-runtime`), React/Tailwind renderer with no DOM in tests.

**Spec:** `docs/prd.md` §33 (in-repo source of truth) + Notion "🧠 Memory" (`3d0d33dfffca80069188f30bad24ed9c`, the locked proposal with the interview record).

## Global Constraints

- **Do not touch code before this plan is approved** — the round stops here. When executing: branch `memory` (this worktree), TDD, `npm run gate` per phase, `npm run test:live` when `npm run live:why` prints (it will: the bridge and `hv-*.ts` are Pi-facing). Symlink `.env` first: `ln -s ~/Documents/Github/HappyVibe/.env .env` — a worktree has none and the live batch reads green in 5 s having tested nothing (CLAUDE.md §Tests).
- **`npm run lint` / `npm run format` are never run** (CLAUDE.md).
- **Caps (§33):** body ≤ 4096 bytes · description ≤ 150 chars · 100 memories per scope · slug `^[a-z0-9][a-z0-9-]{0,63}$`.
- **File format (§33):** `name`, `description`, `metadata: {type, originSessionId?, modified}` — nested, never flat. Types exactly `user | feedback | project | reference`.
- **Store:** `<agentDir>/memory/` (global) and `<agentDir>/memory/workspaces/<key>/` where `key = sha256(realpath(parent of --git-common-dir))[:16]` when the workspace is a git repo, else `sha256(normalized path)[:16]`. Never in the user's repo.
- **The model never supplies a path.** Every tool takes `name`; main derives slug + dir and realpath-checks containment (`=== dir || startsWith(dir + sep)`, never bare `startsWith`).
- **Gate:** `memory_save` and `memory_forget` default `ask` (nothing to add — a registered tool not in `SAFE_TOOLS` asks); `memory_recall` joins `SAFE_TOOLS`; all three join `PLAN_PASS_TOOLS`.
- **Vocabulary in the UI:** Memory · Remember(ed) · Recall(ed) · Forget/Forgot · Global · Workspace. Never "auto memory", "topic file", "index" (say "what the agent sees every turn"). Never "AI" (the count is pinned at one).
- **Audit data never carries the body** (§19). Types: `memory.saved` · `memory.recalled` · `memory.forgotten` · `memory.refused` · `memory.edited` · `memory.imported`.
- **Every blocking envelope is ALWAYS answered** by main (`"ok"`/text or `"ERROR: …"`), or the bridge hangs.
- **Every `EMPTY_COPY`/`HOWTO_COPY` key needs a `copy="key"` call site** or its test fails (§20 round 17).
- **New tool names go in `INTENT_TOOLS`?** No — declare `intent` in each tool's own schema (the `ask_user` pattern) so `stripIntent` removes it when the intent switch is off.
- Commit per task. Messages: `feat(memory): …` / `test(memory): …` / `docs: …`. Never `git stash` bare (worktree rule).

```ts
// src/main/memory/frontmatter.ts
import { parse as parseYaml, stringify as stringifyYaml } from "yaml";

export const MEMORY_TYPES = ["user", "feedback", "project", "reference"] as const;
export type MemoryType = (typeof MEMORY_TYPES)[number];

export interface MemoryDoc {
  name: string;
  description: string;
  type: MemoryType;
  originSessionId?: string;
  modified?: string;
  body: string;
}

const FENCE = /^---\r?\n([\s\S]*?)\r?\n---\r?\n?([\s\S]*)$/;

/** Reads every shape Claude Code writes (metadata.type alone · + node_type/originSessionId · + modified)
 *  and ours. Flat `type:` is NOT accepted: no file on disk uses it, and accepting it would make a
 *  second shape we then have to keep writing. Malformed YAML ⇒ null, never a throw (the skills rule). */
export function parseMemoryFile(text: string): MemoryDoc | null {
  const m = FENCE.exec(text);
  if (!m) return null;
  let fm: unknown;
  try { fm = parseYaml(m[1]); } catch { return null; }
  if (!fm || typeof fm !== "object") return null;
  const f = fm as Record<string, unknown>;
  const meta = (f.metadata ?? null) as Record<string, unknown> | null;
  const name = typeof f.name === "string" ? f.name.trim() : "";
  const description = typeof f.description === "string" ? f.description.trim() : "";
  const type = meta && typeof meta.type === "string" ? meta.type : "";
  if (!name || !description || !(MEMORY_TYPES as readonly string[]).includes(type)) return null;
  const doc: MemoryDoc = { name, description, type: type as MemoryType, body: m[2].replace(/^\r?\n/, "").trimEnd() };
  if (meta && typeof meta.originSessionId === "string") doc.originSessionId = meta.originSessionId;
  if (meta && typeof meta.modified === "string") doc.modified = meta.modified;
  else if (meta && meta.modified instanceof Date) doc.modified = meta.modified.toISOString();
  return doc;
}

export function serializeMemoryFile(doc: MemoryDoc): string {
  const metadata: Record<string, string> = { type: doc.type };
  if (doc.originSessionId) metadata.originSessionId = doc.originSessionId;
  if (doc.modified) metadata.modified = doc.modified;
  // yaml.stringify quotes what needs quoting (colons, leading symbols) — never hand-roll it.
  const head = stringifyYaml({ name: doc.name, description: doc.description, metadata }).trimEnd();
  return `---\n${head}\n---\n\n${doc.body.trimEnd()}\n`;
}
```

Note: `yaml.stringify` may render an ISO date string unquoted; `parseYaml` then yields a `Date` — the `instanceof Date` branch above handles it. If the round-trip test shows the `modified` string re-quoted, that is fine too (equality is on the parsed value).

// src/main/memory/secretScan.ts
/** §33: "do not save secrets" is ENFORCED here, not described. Exported so the
 *  How-memory-works disclosure test can pin its copy to this list. Placeholders
 *  like `sk-REPLACE` must NOT match — hence the length floors. */
export const SECRET_PATTERNS = [
  { id: "openai", label: "an API key (sk-…)", re: /\bsk-[A-Za-z0-9_-]{20,}\b/ },
  { id: "github", label: "a GitHub token (ghp_/gho_/ghs_…)", re: /\bgh[pousr]_[A-Za-z0-9]{30,}\b/ },
  { id: "aws", label: "an AWS access key (AKIA…)", re: /\bAKIA[0-9A-Z]{16}\b/ },
  { id: "bearer", label: "a bearer token", re: /\bBearer\s+[A-Za-z0-9._~+/=-]{20,}/ },
  { id: "pem", label: "a private key block", re: /-----BEGIN [A-Z ]*PRIVATE KEY-----/ },
  { id: "slack", label: "a Slack token (xox…)", re: /\bxox[abprs]-[A-Za-z0-9-]{10,}\b/ },
] as const;

export function findSecret(text: string): { id: string; label: string } | null {
  for (const p of SECRET_PATTERNS) if (p.re.test(text)) return { id: p.id, label: p.label };
  return null;
}

import fs from "node:fs";
import path from "node:path";
import crypto from "node:crypto";
import { MEMORY_TYPES, parseMemoryFile, serializeMemoryFile, type MemoryDoc, type MemoryType } from "./frontmatter";
import { findSecret } from "./secretScan";

export const CAPS = { body: 4096, description: 150, perScope: 100 } as const;
const INDEX = "MEMORY.md";

export function memoryRoot(agentDir: string): string { return path.join(agentDir, "memory"); }
export function workspaceMemoryDir(agentDir: string, key: string): string { return path.join(memoryRoot(agentDir), "workspaces", key); }

/** §33: repo ⇒ every worktree of one clone shares (parent of --git-common-dir);
 *  else the normalized path. 16 hex chars, like Claude Code's project slugs are stable. */
export function workspaceMemoryKey(wsPath: string, gitCommonDir: string | null): string {
  const basis = gitCommonDir ? path.dirname(path.resolve(gitCommonDir)) : path.resolve(wsPath);
  return crypto.createHash("sha256").update(basis.replace(/[\\/]+$/, "")).digest("hex").slice(0, 16);
}

const SLUG = /^[a-z0-9][a-z0-9-]{0,63}$/;
export function slugify(name: string): string | null {
  const s = name.toLowerCase().normalize("NFKD").replace(/[̀-ͯ]/g, "").replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "").slice(0, 64).replace(/-+$/, "");
  return SLUG.test(s) ? s : null;
}

export interface MemorySummary { slug: string; name: string; description: string; type: MemoryType; modified?: string; originSessionId?: string; bytes: number }

/** Containment: realpath the nearest EXISTING ancestor (the file is usually absent), then
 *  `=== dir || startsWith(dir + sep)` — the hv-child-guard rule, never a bare startsWith. */
function fileFor(dir: string, slug: string): string {
  const p = path.join(dir, `${slug}.md`);
  const realDir = fs.realpathSync(dir);
  const realParent = fs.realpathSync(path.dirname(p));
  if (realParent !== realDir) throw new Error("memory path escapes its scope");
  return path.join(realParent, path.basename(p));
}

export function listMemories(dir: string): MemorySummary[] {
  let names: string[];
  try { names = fs.readdirSync(dir); } catch { return []; }
  const out: MemorySummary[] = [];
  for (const n of names) {
    if (!n.endsWith(".md") || n === INDEX) continue;
    const slug = n.slice(0, -3);
    if (!SLUG.test(slug)) continue;
    let text: string;
    try { text = fs.readFileSync(path.join(dir, n), "utf8"); } catch { continue; }
    const doc = parseMemoryFile(text);
    if (!doc) continue;
    out.push({ slug, name: doc.name, description: doc.description, type: doc.type, modified: doc.modified, originSessionId: doc.originSessionId, bytes: Buffer.byteLength(text) });
  }
  return out.sort((a, b) => (b.modified ?? "").localeCompare(a.modified ?? "") || a.name.localeCompare(b.name));
}

export function readMemory(dir: string, slug: string): MemoryDoc | null {
  if (!SLUG.test(slug)) return null;
  try { return parseMemoryFile(fs.readFileSync(fileFor(dir, slug), "utf8")); } catch { return null; }
}

/** GENERATED, never model-edited: one `- slug — description` line per memory, grouped by type in
 *  MEMORY_TYPES order. Bounded by CAPS by construction. */
export function regenerateIndex(dir: string): void {
  const all = listMemories(dir);
  const parts: string[] = [];
  for (const t of MEMORY_TYPES) {
    const rows = all.filter((m) => m.type === t).sort((a, b) => a.slug.localeCompare(b.slug));
    if (rows.length === 0) continue;
    parts.push(`## ${t}\n` + rows.map((m) => `- ${m.slug} — ${m.description}`).join("\n"));
  }
  writeAtomic(path.join(dir, INDEX), parts.join("\n\n") + (parts.length ? "\n" : ""));
}

export function indexText(dir: string): string {
  try { return fs.readFileSync(path.join(dir, INDEX), "utf8"); } catch { return ""; }
}

export function estimateTokens(dir: string): { count: number; tokens: number; items: { name: string; tokens: number }[] } {
  const items = listMemories(dir).map((m) => ({ name: m.slug, tokens: Math.ceil(`- ${m.slug} — ${m.description}`.length / 4) }));
  return { count: items.length, tokens: items.reduce((a, b) => a + b.tokens, 0), items };
}

function writeAtomic(file: string, text: string): void {
  const tmp = `${file}.${process.pid}.${Date.now()}.tmp`;
  fs.writeFileSync(tmp, text);
  fs.renameSync(tmp, file);
}

// ponytail: one global write queue (plans.ts idiom); per-dir queues if it ever contends.
let queue: Promise<unknown> = Promise.resolve();
function serialize<T>(fn: () => T): Promise<T> {
  const run = queue.then(fn, fn);
  queue = run.catch(() => undefined);
  return run;
}

export type SaveResult = { ok: true; slug: string; replaced: boolean } | { ok: false; reason: string };

export function saveMemory(dir: string, input: { name: string; description: string; type: string; content: string; originSessionId?: string; now?: Date }): Promise<SaveResult> {
  return serialize(() => {
    const slug = slugify(input.name ?? "");
    if (!slug) return { ok: false, reason: `"${input.name}" cannot be a memory name — use letters, digits and spaces.` };
    if (!(MEMORY_TYPES as readonly string[]).includes(input.type)) return { ok: false, reason: `type must be one of ${MEMORY_TYPES.join(", ")}.` };
    const description = (input.description ?? "").trim();
    if (!description) return { ok: false, reason: "description is required (one line the agent can scan)." };
    if (description.length > CAPS.description) return { ok: false, reason: `description is ${description.length} chars; the limit is ${CAPS.description}.` };
    const body = (input.content ?? "").trim();
    if (!body) return { ok: false, reason: "content is required." };
    if (Buffer.byteLength(body) > CAPS.body) return { ok: false, reason: `content is ${Buffer.byteLength(body)} bytes; the limit is 4 KB (${CAPS.body}). A memory is a durable fact, not a document.` };
    const secret = findSecret(`${description}\n${body}`);
    if (secret) return { ok: false, reason: `refused: the content looks like it contains ${secret.label}. Memories are plain files; keep secrets in .env or the keychain.` };
    fs.mkdirSync(dir, { recursive: true });
    const file = fileFor(dir, slug);
    const replaced = fs.existsSync(file);
    if (!replaced && listMemories(dir).length >= CAPS.perScope) {
      return { ok: false, reason: `memory is full (${CAPS.perScope}). Forget or merge existing memories first.` };
    }
    const doc: MemoryDoc = { name: slug, description, type: input.type as MemoryType, body, modified: (input.now ?? new Date()).toISOString() };
    if (input.originSessionId) doc.originSessionId = input.originSessionId;
    writeAtomic(file, serializeMemoryFile(doc));
    regenerateIndex(dir);
    return { ok: true, slug, replaced };
  });
}

export function forgetMemory(dir: string, slug: string): Promise<boolean> {
  return serialize(() => {
    if (!SLUG.test(slug)) return false;
    let file: string;
    try { file = fileFor(dir, slug); } catch { return false; }
    if (!fs.existsSync(file)) return false;
    fs.rmSync(file);
    regenerateIndex(dir);
    return true;
  });
}

// pi-runtime/extensions/hv-memory.ts
import fs from "node:fs";
import path from "node:path";

export const MEMORY_TOOLS = ["memory_save", "memory_recall", "memory_forget"] as const;

export const MEMORY_POLICY =
  "You have a persistent memory across sessions, in two scopes: global (about the user, every project) and workspace (this project). " +
  "The index below lists every memory by name; open one in full with memory_recall when it is relevant. " +
  "Save with memory_save only durable, non-obvious facts a future session will need: stable preferences of the user, lessons from corrections or confirmed approaches, " +
  "project facts you cannot recover from the code or git history, and pointers to external references. " +
  "Do not save code structure, file paths, git history, one-off fixes, active task state, secrets, or anything AGENTS.md already says. " +
  "When the user says \"remember …\", save it this turn; \"forget …\", call memory_forget this turn. " +
  "Prefer updating an existing memory (same name) over creating a new one. " +
  "Memories are hints, not evidence: verify a mutable claim against the code or a tool before acting on it.";

export function readIndex(dir: string | undefined): string {
  if (!dir) return "";
  try { return fs.readFileSync(path.join(dir, "MEMORY.md"), "utf8").trim(); } catch { return ""; }
}

/** The per-turn block. `workspace: null` = the workspace toggle is off ⇒ no workspace block. */
export function renderMemorySection(o: { append: string; global: string; workspace: string | null }): string {
  const policy = "<memory-policy>\n" + MEMORY_POLICY + (o.append.trim() ? "\n" + o.append.trim() : "") + "\n</memory-policy>";
  const g = `<memory scope="global" trust="untrusted">\n${o.global.trim() || "No global memories yet."}\n</memory>`;
  const w = o.workspace === null ? "" : `\n\n<memory scope="workspace" trust="untrusted">\n${o.workspace.trim() || "No workspace memories yet."}\n</memory>`;
  return "\n\n" + policy + "\n\n" + g + w;
}

export interface ScopeWeight { count: number; tokens: number; items: { name: string; tokens: number }[] }
const tok = (s: string): number => Math.ceil(s.length / 4);

function weigh(index: string): ScopeWeight {
  const items = index.split("\n").filter((l) => l.startsWith("- ")).map((l) => ({ name: l.slice(2).split(" — ")[0], tokens: tok(l) }));
  return { count: items.length, tokens: items.reduce((a, b) => a + b.tokens, 0), items };
}

export function memoryTokenLines(globalDir: string | undefined, workspaceDir: string | undefined): { global: ScopeWeight; workspace: ScopeWeight; policy: number } {
  return { global: weigh(readIndex(globalDir)), workspace: weigh(readIndex(workspaceDir)), policy: tok(MEMORY_POLICY) };
}
